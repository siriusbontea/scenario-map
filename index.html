Point overlays
Military-capable airfields — OurAirports (CC0 / Public Domain), joined with runways.csv for runway length and surface.
Airport tier (C-5 / C-17 / C-130) derived from the longest open runway: C-5 ≥ 8,000 ft paved, C-17 ≥ 6,000 ft paved, C-130 ≥ 4,000 ft hard surface (paved OR gravel/oiled). Anything shorter is dropped.
Hospitals (US) — HIFLD Hospitals via FEMA-hosted ArcGIS service.
Hospitals (CA) — StatCan Open Database of Healthcare Facilities v1.1 (Statistics Canada Open License).
Hospitals (GL / IS) — OpenStreetMap via Overpass API (amenity=hospital|clinic, ODbL). HIFLD and ODHF have no coverage outside US/CA.
Hospital map toggles split major hospitals (trauma centres, large acute-care facilities) from other hospitals (standard acute and limited clinics). Marker color (Major / Standard / Limited) still reflects capability tier. Major hospitals and major military bases show an emphasis ring on the map.
Walmart stores — OpenStreetMap via Overpass API (brand=Walmart, ODbL).
Walmart tier (Supercenter / Discount Store / Neighborhood Market) derived from OSM shop/amenity/name tags. Sub-section artifacts (pharmacy counters, garden centres, trolley bays, photo labs) are dropped — they aren't separate destinations.
Pathogen-spread congregate-setting overlays
Military installations — OpenStreetMap via Overpass API (military=*, named features only). HIFLD MIRTA migrated off the public FEMA service, so OSM is the unified source for US / CA / GL / IS.
Military map toggles split major installations (OSM base / naval_base / airfield / garrison) from other military sites (offices, recruiting stations, armoury, ranges, training areas). Marker color (Base / Guard/Reserve / Range/Training) still reflects OSM military tag tier.
Correctional facilities (US) — HIFLD Prison Points via FEMA-hosted ArcGIS service (federal, state, county, city, juvenile).
Correctional facilities (CA / GL / IS) — OpenStreetMap via Overpass API (amenity=prison, ODbL).
Corrections tier (Federal/Military/Maximum / State/County/Medium / Local/Jail/Juvenile) derived from HIFLD TYPE+SECURELVL; OSM uses operator+name.
Schools (US) — HIFLD Public Schools, Private Schools, and Colleges & Universities (HIFLD wraps NCES CCD/PSS and IPEDS).
Schools (CA / GL / IS) — OpenStreetMap via Overpass API (amenity=school|college|university, ODbL).
School tier (College/University / K-12 enrollment ≥ 500 / K-12 enrollment 100–499) derived from HIFLD ENROLLMENT; schools below 100 are dropped. OSM lacks enrollment counts so it tiers by education level only.
Food production (US) — USDA FSIS Meat, Poultry & Egg Product Inspection Directory, addresses geocoded via the US Census Geocoder.
Food production (CA / GL / IS) — OpenStreetMap via Overpass API (industrial=slaughterhouse|meat|food|fish, ODbL). CFIA doesn't publish a bulk CSV of licensed establishments through the Open Government portal, so OSM is the unified source for the US's three foreign neighbours.
Food production tier (Slaughter / Processing / Egg/Other) derived from the FSIS / CFIA activities field. Meatpacking slaughter floors were the strongest documented congregate-outbreak driver of COVID-era food-industry transmission.
Long-term care (US) — HIFLD Open Nursing Homes (wraps CMS Provider Information; includes nursing homes and assisted-living facilities).
Long-term care (CA) — StatCan ODHF v1.1 (second pass, filtered to long-term care / nursing / palliative facility types).
Long-term care (GL / IS) — OpenStreetMap via Overpass API (amenity=nursing_home + social_facility=*, ODbL).
Long-term care tier (Skilled Nursing / Assisted Living / Hospice/Adult Day) reflects clinical acuity, which proxies outbreak case-fatality risk.
Sidecar (not rendered on map)
Airport passenger-flow edges — BTS T-100 Segment data, aggregated to airport-pair flows in data/airport_edges.csv for downstream metapopulation modelling.
Point data clipped to scenario land polygons at fetch time (point-in-polygon test). Last refreshed when scripts/build_overlays.py was run.
